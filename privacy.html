Privacy policy

Saga Stories · Last updated 13 October 2026

Saga Stories is a personal automation that publishes a daily animated children's story to a single YouTube channel owned by the person who runs the app. This policy explains what Google user data the app uses and how.

Who signs in

Only the channel owner signs in, once, to authorise uploads. The app has no other users and no public sign-in.

Google data the app uses

With the owner's permission, the app uses the YouTube Data API to:

  • upload the day's video and set its title, description, tags and thumbnail;
  • list the channel's recent uploads, so it does not publish the same day twice or repeat a title;
  • create and update the channel's playlists;
  • read the channel's own YouTube Analytics reports, to see which stories viewers enjoy.

It does not read the owner's email, contacts, files, or any data outside YouTube, and it does not access other people's channels or viewer information.

How the data is stored

The OAuth token that grants this access is stored as an encrypted secret in the app's private deployment and on the owner's own computer. Channel data the app reads is used only while a daily run is in progress and is not kept in a database.

Sharing

Google user data is not sold, shared with third parties, or used for advertising. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements, and YouTube's Terms of Service. Google's own handling of data is described in the Google Privacy Policy.

Children

The videos are made for children and are marked "made for kids" on YouTube. The app does not collect any information from children or other viewers.

Revoking access

The owner can revoke the app's access at any time at myaccount.google.com/permissions. When access is revoked, the stored token stops working.

Contact

Questions about this policy can be raised by opening an issue.
